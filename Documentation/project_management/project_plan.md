# Project Plan

## Development Methodology

The **Incremental Development Methodology** will be chosen for the project. Development is divided up into multiple increments.

**Advantages**
- There is a usable version of the software delivered early.
- The ability to add new features later provides **felxibililty**.

**Phases of Incremental Model**
- Requirement Analysis
- Design & Development
- Testing
- Implementation
